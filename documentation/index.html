Installation, Customization (Colors, Fonts, Content), Page Structure, Credits, Changelog, and Support.

1. Installation

RouteGo is built with zero build-step dependencies using clean HTML5, CSS3 custom properties, and vanilla ES6+ JavaScript modules.

  1. 1. Unzip or clone the project folder onto your machine or web host.
  2. 2. Serve the root folder using any static HTTP server (e.g. python -m http.server 8080, VS Code Live Server, Netlify, Vercel, or Apache/Nginx).
  3. 3. Open http://localhost:8080/index.html in your browser.

2. Customization (Colors, Fonts, Content & Integrations)

  • • Color Palette: Edit the CSS custom properties in assets/css/style.css under :root (--midnight: #0A0F24, --asphalt: #121A33, --amber: #FFB020, --coral: #FF5C4D, --teal: #19D3B5, --cream: #FFF7E8).
  • • Typography: Modify --font-display (Sora), --font-body (DM Sans), and --font-mono (JetBrains Mono) in assets/css/style.css.
  • • Routes, Buses & Promo Codes: Update window.ROUTEGO_DATA inside assets/js/plugins/data.js.
  • • Payment & Auth Gateways: Search for TODO: comments inside assets/js/main.js, assets/js/booking.js, and pages/payment.html to wire in Stripe, Razorpay, Formspree, or OAuth APIs.
